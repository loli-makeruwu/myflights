# MyFlights — Flight Deal Monitor

כלי אישי לסריקת טיסות מישראל ליפן, קוריאה ותאילנד, עם עדכונים בטלגרם דרך GitHub Actions. אין צורך במפתח בתשלום.

## מה הסורק עושה

- בודק Google Flights ואת Kiwi.com בכל הרצה, בלי מפתח.
- Google Flights נסרק ישירות בחמישה ימי יציאה לאורך כל חלון. שדות תעופה חלופיים (NRT/HND, ICN/GMP, BKK/DMK) נבדקים בנפרד.
- במחיר הלוך־חזור מ-Google מופיעה רק טיסת ההלוך. המחיר נשאר 🟡 עד שבודקים את החזור ידנית, והוא לא נספר כדיל מאומת.
- Kiwi.com מחזיר הלוך וחזור בכרטיס אחד, ולכן מחיר שעומד בסף יכול להיות דיל מאומת. בהלוך־חזור נבדקים אותם חמישה ימי יציאה, עם טווח חזרה לפי אורך השהייה, ועד 25 תוצאות ליום.
- Aviasales נוסף רק אם מגדירים `TRAVELPAYOUTS_TOKEN` חינמי. זה מטמון של חיפושים, לא חיפוש חי, והוא מכסה את חודש החלון.
- SerpAPI הוא גיבוי בלבד, ורק אם החיפוש הישיר ב-Google נכשל וגם `SERPAPI_KEY` כבר מוגדר. הוא לא נדרש.
- משך הטיסה הוא זמן אמיתי מדלת לדלת: זמן באוויר ועוד ההמתנה בשדה המעבר. חיסור שעון מקומי בין ישראל לאסיה לא בשימוש.
- נשמרות רק טיסות של עד 20 שעות ועד עצירה אחת לכל כיוון. כרטיס עם מעבר עצמי, עיר נסתרת או כרטיס לזריקה לא נכלל.
- ברוב הימים הסריקה היא הלוך־חזור מישראל. בערך כל יום שלישי (`search_cycle_days`) הסריקה חד־כיוונית, והכיוון מתחלף.
- שולח לטלגרם את כל הטיסות שעברו את כללי הזמן והעצירות, במספר הודעות אם הרשימה ארוכה, גם כשאין דיל מתחת לסף. כותרות RSS הן הקשר בלבד, לא הצעת מחיר אישית.
- ליד כל מחיר יש קישורי השוואה ל-Kayak, Skyscanner, Momondo, ולמקורות שלא סיפקו את המחיר עצמו.

Amadeus לא בשימוש.

## ספי מחיר (USD)

|---|---:|---:|
| ישראל ↔ יפן | $450 | $750 |
| ישראל ↔ קוריאה | $350 | $600 |
| ישראל ↔ תאילנד | $300 | $550 |

הספים נמצאים ב-`routes_config.json`. המחיר יכול להשתנות עד פתיחת הקישור. יש לאמת את המחיר הסופי אצל חברת התעופה או באתר ההזמנה לפני רכישה.

## הגדרה

ב-GitHub Repository → Settings → Secrets and variables → Actions:

- `TELEGRAM_BOT_TOKEN` — טוקן הבוט
- `TELEGRAM_CHAT_ID` — הצ'אט שאליו נשלח הסיכום
- `TRAVELPAYOUTS_TOKEN` — אופציונלי. טוקן חינמי מפרופיל שותפים של Travelpayouts, לתוספת מטמון Aviasales
- `SERPAPI_KEY` — אופציונלי. גיבוי רק כש-Google הישיר נכשל

הסריקה רצה ב-06:00 וב-18:00 UTC, ואפשר להפעיל אותה ידנית ב-Actions → Flight Outlier Check → Run workflow. אל תכניסו טוקנים לקוד או לקבצים ציבוריים.

### הרצה מקומית

```bash
pip install -r requirements.txt
python check_flights.py --sample --no-telegram
```

`--sample` בודק רק את המסלול והחלון הראשונים. `--no-telegram` מדפיס את הסיכום בלי לשלוח אותו. הרצה רגילה דורשת את שני סודות הטלגרם.
