# מדריך לבניית בוט טלגרם להתראות מחירים חריגים

## שלב 1: יצירת הבוט בטלגרם (2 דקות)

1. פתח את טלגרם וחפש את **@BotFather**.
2. שלח לו `/newbot`.
3. בחר שם לבוט (למשל: `MyFlightOutlierBot`).
4. בחר username (חייב להסתיים ב-`bot`, למשל: `myflightoutlier_bot`).
5. BotFather ישלח לך **טוקן** (משהו כמו `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

**שמור את הטוקן בסוד!** אל תשתף אותו.

## שלב 2: קבלת ה-Chat ID שלך

1. שלח הודעה כלשהי לבוט שיצרת (למשל "היי").
2. פתח בדפדפן:
   `https://api.telegram.org/bot<הטוקן_שלך>/getUpdates`
3. חפש בתוצאה את `"chat":{"id":` — המספר הזה הוא ה-Chat ID שלך.

## שלב 3: הרצת הבוט

לאחר שתיתן לי את הטוקן וה-Chat ID (או שתשים אותם בקובץ `.env`), אוכל לכתוב לך סקריפט Python ש:

- בודק את המסלולים (או שולח לך את הקישורים + תזכורת)
- שולח התראה לטלגרם כשמוצא משהו מעניין
- אפשר להריץ אותו ידנית או לשים על cron / GitHub Actions

### דרישות
```bash
pip install python-telegram-bot requests
```

## מה הבוט יכול לעשות כרגע (גרסה ראשונה)

- שליחת דשבורד יומי עם הקישורים לחלונות פברואר וקיץ
- תזכורת לבדוק את הספים
- בהמשך: חיבור ל-API אמיתי (SerpAPI / Amadeus) לבדיקה אוטומטית
